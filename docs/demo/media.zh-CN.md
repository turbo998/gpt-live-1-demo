# 录像来源与边界

[English](media.md) | 简体中文

原资料录像日期为 **2026-09-22**。随附说明称：回答来自真实 Azure GPT-Live，
提问与旁白为离线合成音频，只录应用画面，未录私人桌面或真人麦克风。
这些是原资料的历史陈述，**不是本次整合的新验证，也不是公开分发批准**。

原说明记录了自然对话/打断、服务端时钟、十加二十返回三十及带来源的语音触发
原生搜索。断开后的独立搜索测试是另一事件。来源证明检索，不保证回答准确、
最新或全部来源都是官方。

界面切换与口语能力独立。**英文口语请求未独立完成**，当时模型仍在解释搜索结果。
不能把录像作为英文口语成功验收；自然打断也不证明后台工作被取消。
断开后的架构旁白不是模型回答，视频总长不等于模型计费会话时长。

## 公开分发门槛

Git 不包含视频，本说明也不自动为视频清关。Release 前须完整审阅所有画面和音轨，
检查元数据、字幕和附件，只处理副本，再对最终文件完整解码/播放并计算哈希。
OCR、抽帧、音量检查或解码成功不能单独证明脱敏通过。
禁止上传原客户 ZIP 或环境所有者私有材料。

Word 从公开文本与架构重建，不直接修改原文档；客户 ZIP 用固定白名单重新生成。
无法可靠完成视频审核时，应排除视频并保持完整媒体发布阻塞。新真实录制须另获
授权与费用边界，不得用合成模型答案替代真实回答。
